# M5.1 费用透明化

## 状态

已完成基础费用追踪与页面展示，未配置未经核实的火山方舟价格。

当前 Producer 模型为 `doubao-seed-evolving-latest-version`。仓库和历史 Runtime 证据未提供该模型的官方输入、输出或缓存单价，因此真实任务只显示 Token 和“价格未配置”，不估算人民币金额。

## 规则

- 用量按所有 `span.model_request_end` 事件累计，支持多请求和重复事件去重后的事件集。
- 缓存读取 Token 从总输入中扣除，再按缓存单价计算，避免重复计费。
- 存在缺失或未完成请求时标记 `partial`，不把部分金额冒充总费用。
- 价格通过 `LOCALMINIDRAMA_AGENT_PRICES_JSON` 配置，包含模型、单价、货币、价格版本、生效时间和来源。
- 无价格时状态为 `unconfigured`；前端显示原因，不阻止聊天。

## 验证

- 后端测试：87/87 通过，包含无价格、缓存扣除、部分用量测试。
- 前端构建：通过。
- 既有真实 Producer 任务可读取完整 Token 记录；由于价格未核实，费用金额保持不可计算。

## 后续

取得并审核官方价格后，再配置价格表并补充作品/日期聚合展示；本轮不调用收费模型，不修改账户计费配置。
