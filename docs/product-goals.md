# LocalMiniDrama 产品目标

**版本：** v1.0  
**日期：** 2026-10-13

---

## 产品定位

**AI 智能短剧导演与制作系统**

让 AI 团队与图片、视频模型形成真正的专业影视制作能力，逐步实现从剧本到成片的智能化流程。

---

## 核心目标

### 目标 A：专业 AI 影视制作团队

实现完整的专业影视制作能力：

1. **总导演** - 镜头决策与整体把控
2. **剧本分析** - 剧情理解与分镜设计
3. **摄影指导** - 构图、运镜、景别设计
4. **表演指导** - 人物动作与表演连续性
5. **美术指导** - 角色、场景、道具一致性
6. **制作执行** - 图片、视频生成
7. **质量检查** - 视觉质量验收与缺陷识别
8. **制作管理** - 成本控制与调用记录

**质量标准：**
- 不以 Agent 已创建、接口调用成功代替专业质量验收
- 必须有可验证的专业制作闭环
- 必须有真实影视产物交付

### 目标 B：智能短剧导演助手

完整制作流程：

```
剧本 → 自动分镜 → 视觉资产 → 首帧 → 视频 → 声音 → 剪辑 → 质量检查 → 成片
```

**实施原则：**
- 渐进式智能化，不追求一开始完全无人值守
- 制作人负责创意方向、预算控制、重要决策和最终验收
- AI 团队负责执行层面的专业制作工作

---

## 当前里程碑

### 里程碑 1：A/B 镜头专业制作闭环

**目标：** 使现有 AI 影视团队具备可验证的 A/B 镜头专业制作能力

**范围：**
- 导演方案 → 图片生成 → 视频生成 → 质量检查 → 修正迭代

**验收标准：**
- 可实际操作的制作工作流
- Agent 到生成任务的完整追踪
- 真实图片、视频产物
- 专业质量评价

### 里程碑 2：完整场景制作

**目标：** 扩展到完整场景的多镜头制作

**范围：**
- 场景级镜头编排
- 镜头间连续性
- 场景级质量把控

**验收标准：**
- 可观看的场景样片
- 完整镜头清单
- 质量报告与成本记录

### 里程碑 3：完整剧集制作

**目标：** 实现从剧本到成片的完整流程

**范围：**
- 多场景编排
- 音频合成
- 视频剪辑
- 最终成片

**验收标准：**
- 可播放的完整剧集
- 制作文档与成本报告

## 技术架构

### 现有能力

- ✅ Vue 3 + Element Plus 前端工作台
- ✅ Node.js + Express + SQLite 后端
- ✅ 火山方舟 Agent 集成
- ✅ 多家 AI Provider 接入（通义、火山、可灵、Agnes 等）
- ✅ 图片生成流程
- ✅ 视频生成流程
- ✅ 媒体资产管理
- ✅ 画布工作流可视化

### 需要加强

- ⚠️ Agent 与生成任务的数据关联
- ⚠️ 质量检查结果的回流机制
- ⚠️ 连续性验证的自动化
- ⚠️ 制作决策的可追踪性
- ⚠️ 失败原因的具体定位

---

## 开发原则

1. **复用优先** - 已有能力直接用，不重新开发
2. **影视驱动** - 所有改动解决真实制作问题
3. **渐进智能** - 逐步提升自动化程度
4. **保护数据** - 不破坏生产环境
5. **可追踪性** - 所有决策有证据链
