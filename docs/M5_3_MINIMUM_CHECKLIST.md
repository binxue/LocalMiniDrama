# M5.3 最小开发清单

## 产品缺口

- Revision `rev_e310cfe1-f800-4854-bbb6-b81573f30311` 当前展示原稿、候选稿和审核意见，但候选稿以单栏正文为主，缺少逐段 diff 视图。
- Editor 意见未与具体修改段落建立结构化关联，用户只能阅读整体意见。
- 当前批准入口是整版批准，尚未支持逐项接受、退回或要求继续修订。
- `CONDITIONAL PASS` 与 `not_approved` 已明确分开；需要在差异视图继续保持该边界。
- Session、Task、SHA 等字段目前直接暴露给用户，需保留可追溯性但改为折叠的“技术详情”。

## 最小验收标准

1. 原稿与候选稿可并排查看，删除、增加和修改有稳定高亮。
2. 每条 Editor 意见能定位到候选稿段落或显示“全局意见/无对应段落”。
3. 用户可逐项标记接受、退回或要求继续修订；任何操作生成持久化审阅记录。
4. 未通过或未批准版本不可进入 Canon 或 Script Handoff。
5. `CONDITIONAL PASS` 只表示审核状态，批准状态仍独立显示 `not_approved`。
6. 页面刷新和服务重启后，原稿、候选稿、差异、意见及用户操作记录保持一致。
7. 技术字段可展开查看，默认界面以版本、状态、理由和引用为主。
