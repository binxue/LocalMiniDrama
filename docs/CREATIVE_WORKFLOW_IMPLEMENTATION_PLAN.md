# 专业团队创作成果流程实施计划

2026-10-15；基线852e222，分支codex/localminidrama-quality。

目标：在现有3014工作台实现创作设定→剧情拆解→人物关系→分集正文→专业评定与导出。采用独立实现，不复制参考站代码或剧情；后台继续复用火山Managed Agent团队。

1. **成果契约与保存**：结构化规划明确集数、剧情事件、目标、冲突、因果、节拍、场次、钩子及连续性。复用批次策划，增加不可覆盖的人工规划版本；旧Agent输出保留原样。旧长文可分阶段阅读，不能伪装已完成全剧结构化拆解。
2. **生产输入**：Producer输出可校验规划；人物/互动/结构专家补充设计。Writer只接收本集对应规划、统一设定和专业资料；缺集、无场次或无节拍不能以截断全文代替。单集与批次共用同一入口。Editor审核本次规划和完整正文，独立展示，不自动批准或循环重写。
3. **现有界面**：默认提供设定、剧情拆解、人物关系、剧本、评定切换。规划可编辑为独立版本、保存、刷新恢复及导出；工程ID/原始材料折叠。自然语言聊天与现有分集成果继续复用。
4. **验收和交付**：隔离数据覆盖规划校验、精确选集、版本冲突和旧资料兼容；现有雨林新测试只读展示。真实Agent验证仅使用已有非雨林作品、明确规划目标，不重复已有未知任务。浏览器实际编辑保存/刷新/导出，代码审查、测试/构建、提交推送并核对远端。

边界：不覆盖雨林正文、Canon、历史任务或Runtime；不操作3013/5679，不新建Agent或工作台。已有未提交视听UI与费用文件不属于本轮。

验收标准：用户能先查看和修改明确剧情规划，再按对应规划获得剧本；不会把历史泛化长文、未覆盖集数或模拟文本写成真实专业规划完成。
